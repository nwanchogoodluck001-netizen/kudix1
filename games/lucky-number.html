Quick guide

How to play Lucky Number

Try the number-selection experience in a simple, local demo.

01

Choose a number

Pick exactly one number from 1 through 20.

02

Set a demo amount

Choose a practice amount between ₦100 and ₦2,000. It will not be deducted.

03

Reveal the number

Press Draw Lucky Number to reveal a randomly generated demo result.

04

Check the result

See whether your selection matches, then start another round.

Please note: Matching a number is only a demo outcome. It does not award money, increase your credit, or guarantee any future result. This page is not connected to a payment system or backend.
