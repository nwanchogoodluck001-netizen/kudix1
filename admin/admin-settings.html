Balance Administration
Allow Administrator Balance Adjustments

Permit authorized administrators to make adjustments through the existing balance-management workflow.

Referral balances and activity balances must remain separate. All reward calculations, eligibility checks, balance adjustments, and transaction records must be validated and processed on the server. These fields must not directly modify user balances.
